# mAGEordome
L'application de la fédération pour les circulaires (portail applicatif).

## À quoi elle sert
- Les nouvelles circulaires
- Les "tâches de la semaine": ce qu'il faut faire pour une date (ponctuel, mensuel, annuel), avec les liens vers les circulaires

## Le problème
- Elle mélange le fondamental et le secondaire: beaucoup d'informations ne me concernent pas
- Pas de lien avec mes projets: je dois faire le tri moi-même

## Ce que je vérifie
- Chaque lundi, les tâches de la semaine qui concernent le fondamental ou le primaire ([[Revue du lundi (Processus)]])
- Chaque nouvelle circulaire: les actions pour le primaire, avec la date, vont dans mes tâches
- Dernière circulaire lue: 9847, Organisation de l'année scolaire 2026-2027. Lue en diagonale le 09/11, pas encore traitée: seules les dates principales sont dans le [[Calendrier scolaire 2026-2027]]
